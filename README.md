# 🎬 Cinema VIP - Escolha de Assentos

Uma aplicação web simples e intuitiva para selecionar assentos em uma sala de cinema e enviar a escolha via WhatsApp.

## 🚀 Acesse agora

**[Clique aqui para abrir o Cinema VIP](https://iblackn.github.io/IBLACKN-pq/)**

## ✨ Características

- **Coxão (2 lugares)** - C1, C2
- **Sofá (3 lugares)** - S1, S2, S3
- **Cadeira (1 lugar)** - A1

### Funcionalidades

✅ Seleção visual de assentos com código de cores
- 🟫 Cinza = Assentos disponíveis
- 🟩 Verde = Assento selecionado
- 🟥 Vermelho = Assentos ocupados

✅ Validação de assentos já ocupados
✅ Integração com WhatsApp para enviar a escolha
✅ Design moderno e responsivo

## 📱 Como usar

1. Escolha um assento clicando nele (ficará verde)
2. Clique no botão "📲 Enviar Assento"
3. Será aberto o WhatsApp com a sua escolha
4. Envie a mensagem e pronto!

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)
